# 🤺 击剑对决（Fencing Duel）

一个用 **Scratch** 制作的**双人奥运会剑术对战**游戏！

中国 VS 美国，谁才是剑术之王？

## 🎮 怎么玩

1. 下载 `奥运会剑术比拼（中国VS美国）.sb3` 文件
2. 打开 [Scratch 编辑器](https://scratch.mit.edu/projects/editor/)
3. 菜单栏：文件 → 从电脑中上传 → 选择下载的文件
4. 点击绿旗 🚩 开始游戏！

## 🕹️ 操作说明

- **1P（中国）**：用键盘左边按键攻击/防守
- **2P（美国）**：用键盘右边按键攻击/防守
- 击中对方得分，分数高的获胜！

## ✨ 特点

- 双人对战，适合和朋友一起玩
- 奥运主题，中国 VS 美国
- 音效+特效齐全
